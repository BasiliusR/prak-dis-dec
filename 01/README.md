A. Dasar Teori 
Git dan GitHub merupakan dua tool atau alat dalam dunia pemrograman dengan fungsi yang sama sekali berbeda.
Git adalah sebuah VCS atau Version Control System yang dirancang untuk mencatat setiap perubahan pada file atau kode (Source Code).
Lalu GitHub merupakan sebuah platform online untuk menyimpan, membagikan, serta mengakses kode yang telah dicatat riwayatnya menggunakan Git dari perangkat atau komputer lain.
